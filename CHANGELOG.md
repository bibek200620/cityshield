# Changelog

Notable changes to CityShield will be documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Release versions and dates will be recorded when actually published; the initial baseline below is not a tagged release.

## [Unreleased]

### Added

- Community contribution guidance, security reporting policy, software citation metadata and GitHub issue and pull request templates.

### Existing research baseline

- Bengaluru municipal map, bilingual ward search, city runoff screening and synthetic pilot flood simulation with FloodGNN.
- Historical Landsat-derived heat visualization and optional local heat training.
- Common-grid pilot flood/heat exposure, current weather estimates and driving route comparison.
- Offline ERA5-Land temperature regression experiment and documented evaluation limitations.
- Backend automated tests and frontend CI checks.

These baseline capabilities predate this changelog; this list is not a complete release history. See [commit history](https://github.com/bibek200620/cityshield/commits/main/) and [research documentation](docs/BENGALURU_EVALUATION.md).
